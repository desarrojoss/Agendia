# Agendia

Reservas en línea para negocios que trabajan con citas: tus clientes reservan solos, a cualquier hora, desde el celular.

Proyecto de [DesarroJoss](https://github.com/desarrojoss). En construcción: el alcance y las ejecuciones están en [SPEC.md](SPEC.md).

Stack: Next.js 16 + TypeScript + Tailwind v4 + Firebase (solo servidor) + Vercel.

```bash
npm install
cp .env.local.example .env.local   # completar
npm run dev
```
